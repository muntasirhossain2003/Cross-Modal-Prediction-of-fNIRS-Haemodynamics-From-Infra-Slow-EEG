# Archive

Development history of NeuroVascNet, kept for the record. Nothing here is needed to reproduce the paper.

- `notebooks/`: earlier notebooks (v3 to v6, the Maisha and Kaggle versions, smoke tests). The merged notebook in
  `pipeline/` replaced them.
- `logs/`: console logs of earlier full runs.
- `scripts/`: notebook builders, loaders and run commands for those versions, and the technical-report builder.
- `outputs/`, `figures/`: their saved outputs and figures.

Paths inside these files still point at the old layout (for example `G:\research_bio_medical\merge\...`), so they
will not run as they are.
